# Dcom

Dcom is a high-performance full-stack e-commerce web application built for fast, secure, and scalable online shopping.

## Features

* **Product Discovery:** Real-time product search, category selection, and price filtering.
* **Cart & Checkout:** Persistent shopping cart management and seamless payment processing via Stripe Checkout.
* **Performance Caching:** Integrated Redis caching to minimize database query latency and handle high-traffic sessions.
* **State & Analytics:** User session persistence with HTTP-only cookies and order/analytics tracking endpoints.

## Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database & Cache:** MongoDB, Redis
* **Payment Integration:** Stripe API
